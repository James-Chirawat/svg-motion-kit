Finish your frontend with Claude Code.

svg-motion-kit reads your project's real theme, finds where the UX needs help, adds animated SVG that matches your design, and reviews security, accessibility, performance, design and polish. Every finding has file:line evidence, and fixes are applied one reviewed diff at a time. It works in English and Thai.

/plugin install svg-motion-kit --marketplace James-Chirawat/svg-motion-kit
Claude Code before 2.1.275? Use two steps 
/plugin marketplace add James-Chirawat/svg-motion-kit
/plugin install svg-motion-kit@svg-motion-kit

Requires Claude Code and Node.js 18 or later. The bundled scripts have no dependencies and make no network requests.

Eight skills

audit
Every review in one report: weighted score, “do these first”, fix by number.
svg-motion
Finds empty, loading, error, success, offline and upload moments, and draws them in your theme.
theme-extract
Reads Tailwind v3/v4, CSS variables, shadcn/ui, dark mode, radius and fonts.
design-lint
Scores how generic the UI looks, and proposes alternatives grounded in your audience.
ui-audit
Missing states, labels, focus, tap targets, and WCAG contrast from your theme.
perf-audit
Images, Thai fonts, request waterfalls, N+1 calls, caching, bundles.
security-audit
Masked secret scan, .env hygiene, XSS, unauthenticated routes, headers.
polish-audit
Metadata, Open Graph, favicon, 404 and error pages, robots, sitemap, i18n.
