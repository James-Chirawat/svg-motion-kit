# svg-motion-kit v0.1.0: theme-true motion

The first release ships three Claude Code skills. They read your project's real theme, find where the UX needs motion, add animated SVG that matches it, and flag the generic "AI-made" look.

```text
/plugin marketplace add James-Chirawat/svg-motion-kit
/plugin install svg-motion-kit@svg-motion-kit
```

Then ask in your own words, in English or Thai, for example *"add an animated empty state to the orders page"*, *"ทำ loader ให้เข้าธีม"*, or *"why does our landing page look AI-generated?"*

## Skills

- **theme-extract** reads Tailwind v3/v4, CSS variables, shadcn/ui tokens (oklch and HSL triplets), dark-mode strategy, radius, fonts and installed libraries into `.svg-motion/theme.json`. It never runs project code. When it has to guess a primary colour, it marks it as a guess and asks you to confirm.
- **svg-motion** works through the whole job:
  - **Scout:** ranks empty, loading, error, not-found, success, upload, offline and hero moments by user impact.
  - **Render:** fills one of 8 templates from your theme.
  - **Validate:** runs a quality and safety gate.
  - **Place:** exports a typed React component, with no hooks and Server Component-safe, and shows the diff before writing.
- **design-lint** scores how generic a site looks, from 0 to 100, across 12 rules, with file:line evidence. It then proposes three design directions grounded in your audience, with palettes mapped to your existing variables and Thai-capable font pairings.

## Quality

- **Every generated SVG passes `validate-svg`:**
  - colours come only from theme tokens
  - `prefers-reduced-motion` is supported
  - only transform, opacity and stroke properties are animated
  - accessible names are present
  - no scripts or external references
  - scoped CSS and unique ids, so several can share a page
  - under 15 KB
- **Tests and CI:** 37 unit tests on Node 18 and 22, with CI running `claude plugin validate`.
- **Live headless runs** on example projects showed the full chain working in Thai and English (see `docs/TESTING.md`).
- **Eval suite:** correct triggering on 4 of 4 cases, including a case where nothing should fire.
- **Scripts** are plain Node with no dependencies and no network access.
