# Skills

Each folder here is one skill (`<name>/SKILL.md` plus optional `scripts/`, `references/`, `templates/`).

| Skill | Status | Purpose |
|---|---|---|
| `theme-extract` | Done (unreleased) | Read the project's theme (Tailwind v3/v4, CSS variables, shadcn) into `.svg-motion/theme.json` |
| `svg-motion` | Done (unreleased) | Find where motion helps, generate theme-aware animated SVG, place it as a component |
| `design-lint` | Done (unreleased) | Flag the generic "AI-made" look and propose grounded design directions |
| `ui-audit` | Planned (v0.2) | UX states, forms, mobile, microcopy, contrast and accessibility |
| `perf-audit` | Planned (v0.3) | Images, fonts, data fetching, caching, bundle |
| `security-audit` | Planned (v0.4) | Secrets, XSS sinks, client-side auth, headers |
| `polish-audit` | Planned (v0.5) | Design-system use, code health, i18n, meta, edge pages, SEO basics |
| `audit` | Planned (v1.0) | Orchestrates all audits into one report with safe fixes |

See [docs/ROADMAP.md](../../../docs/ROADMAP.md) for the checks and acceptance criteria of each skill.
